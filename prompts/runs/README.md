# Runs Directory

Each prompt execution should have its own folder:

`prompts/runs/<YYYY-MM-DD-short-slug>/`

Recommended files per run:

- `prompt.md` - exact prompt/task used
- `context.md` - optional additional constraints/context
- `result-summary.md` - what changed and why
- `changed-files.txt` - list of touched files
- `verification.md` - commands run and outcomes
