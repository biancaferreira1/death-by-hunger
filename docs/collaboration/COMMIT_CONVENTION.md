# Commit Convention for Prompt Runs

Use this format for prompt-executed work:

`prompt(run): <task-slug> - <intent>`

## Examples

- `prompt(run): wheat-hud-tweak - improve debug readability`
- `prompt(run): readme-expand - add local run instructions`

## Rules

- Keep subject line under 72 characters when possible.
- Focus on why, not only what changed.
- One logical task per commit where possible.
