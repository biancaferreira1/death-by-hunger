# Prompt Run Checklist

Before pushing, confirm:

- [ ] Task file includes clear scope and acceptance criteria.
- [ ] Changes stay within allowed files.
- [ ] `prompts/runs/<task-id>/result-summary.md` is written.
- [ ] `prompts/runs/<task-id>/changed-files.txt` is updated.
- [ ] `prompts/runs/<task-id>/verification.md` records commands and outcomes.
- [ ] Commit message follows `prompt(run): <task-slug> - <intent>`.
